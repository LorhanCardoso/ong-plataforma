
# Plataforma Web para ONGs

Projeto desenvolvido para a disciplina de Desenvolvimento Front-End, com o objetivo de criar a base estrutural de uma plataforma simples voltada para Organizações Não Governamentais.

## Objetivo do Projeto

O sistema foi pensado para ajudar ONGs a apresentarem suas atividades, divulgarem projetos sociais e facilitar o contato com voluntários e apoiadores.

## Estrutura de Pastas

```
ong-plataforma/
├─ index.html
├─ projetos.html
├─ cadastro.html
├─ assets/
│  ├─ css/
│  │  └─ style.css
│  ├─ js/
│  │  └─ app.js
│  │  └─ masks.js
│  │  └─ ui.js
│  └─ images/
│     ├─ logo.png
│     ├─ banner-home.jpg
│     ├─ projeto1.jpg
│     └─ voluntariado.jpg

```

## Como visualizar o projeto

1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` diretamente no navegador.
3. Use os links do menu para navegar entre as páginas.
